# 汇报大纲（完善版）

## 汇报主线

本项目研究真实拍屏视频的几何预处理：从包含背景、透视畸变、手持抖动和屏幕内部动态内容的完整视频中，持续估计物理屏幕平面，并输出稳定的正面屏幕视频。

汇报重点放在三个问题上：

1. 当前边框主导管线如何估计屏幕平面；
2. 我们的方案与逐帧检测、相邻帧光流相比有什么优势；
3. 实验、消融和失败案例如何支撑我们的结论。

核心观点：

> 我们以物理屏幕边框直接决定单应矩阵，避免内部滚动内容主导屏幕平面估计，从而同时提高几何精度和时间稳定性。

# 1. 算法

## 1.1 项目背景与任务

- 拍屏视频包含屏幕外背景、透视畸变、相机抖动和屏幕内部运动，通常不能直接用于后续 OCR、内容恢复或去摩尔纹。
- 本项目处理这些任务之前的几何前端：定位物理屏幕四边形，并将每帧变换到固定的正面屏幕坐标系。
- 核心难点是保留页面滚动和视频播放，同时消除相机运动造成的屏幕平面变化。

背景简单说明后，直接进入当前方案管线。

## 1.2 当前边框主导管线

```text
输入拍屏视频
    ↓
首帧屏幕初始化（人工四角优先，自动检测回退）
    ↓
用上一帧四边形预测四条物理边框的搜索区域
    ↓
沿每条边的内法线采样局部图像 profile
    ↓
选择靠近预测边的高梯度候选点，鲁棒拟合四条边线
    ↓
相邻边线求交，得到当前屏幕四边形
    ↓
几何门控 + LK/RANSAC 内部运动一致性诊断
    ↓
边框失败时自动重检；仍失败则保持上一有效四边形
    ↓
轨迹插值、平滑和透视变换
    ↓
输出固定尺寸的正面屏幕视频
```

管线重点说明三点：

- **物理边框决定单应矩阵。**当前默认方法在预测边框附近做局部 profile 梯度采样，并由四条拟合直线的交点得到屏幕四边形。
- **LK/RANSAC 只做一致性诊断。**内部特征与边框运动冲突时，说明可能存在页面滚动或屏幕内视频运动；只要边框结果有效，仍以物理边框为准。
- **门控和回退保证结果合法。**只有四条边都有有效证据、四边形凸且相对上一帧变化合理时才接受；边框和重检都失败时才保持上一结果。

需要统一方法口径：

- 当前 Proposed 的默认边框观测是 **profile-based border observation**；
- LSD 和 Hough 是边框检测器消融选项，不是当前主方案的默认流程。

## 1.3 与另外两种方法的简要对比

| 方法 | 核心机制 | 主要问题 |
|---|---|---|
| 逐帧检测 | 每帧独立定位屏幕 | 检测噪声造成抖动，弱边框下容易偏移 |
| 相邻帧光流 | 用内部特征逐帧传播四边形 | 容易跟随滚动或视频内容并累积漂移 |
| 当前边框方案 | 物理边框决定四边形，内部光流只做诊断 | 依赖可见、可辨认的屏幕边界 |

一句话概括：逐帧检测相信当前帧，光流相信内部内容运动，当前方案优先相信物理屏幕边框。

# 2. 实验结果

## 2.1 数据集与实验设置

- 完整数据集包含 50 个自采集拍屏视频，共 14,985 帧。
- 五类拍摄条件各 10 个片段：
  1. 静态页面；
  2. 滚动页面；
  3. 屏幕内播放视频；
  4. 弱边框场景；
  5. 困难视角、反光、摩尔纹或背景复杂的挑战场景。
- 当前正式定量评估使用 10 个带标注片段，每类选取 2 个。
- 几何评价排除用于初始化的第 0 帧。
- 三种主方法使用相同输入、初始化、输出画布、标注和指标代码。

## 2.2 可视化 Demo

### 三种原始场景拼接

- 静态页面：展示基础透视畸变和手持抖动；
- 滚动页面：展示物理屏幕运动与全局内容滚动同时存在；
- 屏幕内视频：展示复杂的内部动态内容。

### 每种场景的同步四宫格

```text
原始拍屏视频        | 逐帧检测结果
相邻帧光流结果      | 当前边框方案结果
```

这里的四宫格是“原始视频 + 三种主方法”。

观察重点：

- 屏幕范围是否完整，有无偏移、裁切或黑边；
- 屏幕边缘是否发生抖动或漂移；
- 页面滚动和屏幕内视频是否被正常保留；
- 输出四边形是否始终贴合物理屏幕。

## 2.3 四类评价指标

| 指标类别 | 具体指标 | 含义与方向 |
|---|---|---|
| 几何精度 | 角点 RMSE、四边形 IoU、宽高比误差 | 判断屏幕位置和形状是否准确；RMSE、比例误差越低越好，IoU 越高越好 |
| 时间稳定性 | 相邻帧平移、旋转和尺度变化 | 判断估计轨迹是否平滑，通常越低越好，但必须结合几何精度解释 |
| 细节保持 | 梯度幅值比、Edge Preservation Index | 判断透视变换和重采样后内容细节是否保持；梯度比接近 1、边缘保持指数越高越好 |
| 频域规则性 | FFT 正交误差 | 判断主要纹理方向是否接近正交屏幕网格，误差越低越好；不代表去摩尔纹效果 |

当前证据口径：

- 当前边框方案已经在十片段上重跑了几何和时域指标；
- 细节和频域指标尚未针对当前 `proposal_border` 统一重跑；
- 如果最终汇报需要定量比较全部四类指标，应先补跑当前方案的 detail 和 frequency；在此之前只介绍两类指标的含义，不给出未经当前实验支持的排名。

## 2.4 三种主方法的总体结果

数值为十个评估片段的片段级中位数再次取中位数：

| 指标 | 逐帧检测 | 相邻帧光流 | 当前边框方案 |
|---|---:|---:|---:|
| 角点 RMSE / px ↓ | 30.37 | 31.40 | **3.87** |
| 四边形 IoU ↑ | 0.980 | 0.979 | **0.996** |
| 平移变化 / px·frame⁻¹ ↓ | 2.83 | 4.13 | **2.45** |

主要结论：

- 当前边框方案同时取得最低角点误差、最高 IoU 和最低平移变化。
- 改进不仅表现为轨迹更平滑，更重要的是屏幕四边形更贴近人工标注。
- 这说明物理边框比内部内容运动更适合作为屏幕单应矩阵的主要证据。

## 2.5 分类结果

| 场景 | 逐帧 RMSE | 光流 RMSE | 当前方案 RMSE | 当前方案平移变化 |
|---|---:|---:|---:|---:|
| 静态页面 | 33.13 | 33.49 | **3.60** | 3.26 |
| 滚动页面 | 31.76 | 81.67 | **2.87** | 1.28 |
| 屏幕内播放视频 | 30.08 | 29.46 | **3.75** | 3.25 |
| 弱边框场景 | 157.26 | 155.87 | **9.35** | 1.45 |
| 挑战场景 | **9.62** | 24.90 | 10.70 | **3.74** |

结果解释：

- **滚动页面提升最大。**光流容易跟随页面内容，而边框方案保持在物理屏幕上。
- **弱边框场景明显改善。**当前方案通过上一帧预测的局部搜索带寻找边界，比全帧独立检测更稳定。
- **挑战场景仍是主要限制。**逐帧检测的几何误差略低于当前方案，但当前方案的平移变化为 3.74 px/frame，低于逐帧检测的 5.19 和光流的 8.56。
- 当前方案十个片段中有七个 RMSE 低于 5 px，全部低于 15 px。
- 十个片段均没有 held frame，说明当前结果来自持续边框更新或有效回退，不是靠冻结轨迹制造稳定性。

## 2.6 实验结果小结

- 逐帧检测会受到单帧边界定位误差影响；
- 相邻帧光流在滚动页面上容易发生内容驱动漂移；
- 当前边框方案在总体几何精度和时间稳定性上都最好；
- 主要收益来自把单应矩阵的主证据从内部纹理切换到物理屏幕边界；
- 现阶段的正式数字只支持几何和时域结论，细节和频域仍需对当前方案补跑。

# 3. 消融测试

## 3.1 消融问题

当前消融比较三种物理边框观测方式：

1. 局部 Profile 梯度采样；
2. LSD 线段检测；
3. Hough 线段检测。

三种变体使用相同的后续四边形拟合、门控、回退和渲染流程，只改变边框候选的来源。

## 3.2 消融结果

当前消融使用代表性滚动片段 `scrolling_01`：

| 边框观测方式 | 角点 RMSE / px ↓ | IoU ↑ | 平移变化 / px·frame⁻¹ ↓ | 运行时间 / s ↓ |
|---|---:|---:|---:|---:|
| **Profile 采样** | **3.253** | **0.996038** | **0.752** | **59.21** |
| LSD 线段 | 3.604 | 0.995716 | 0.961 | 285.49 |
| Hough 线段 | 27.335 | 0.974200 | 0.897 | 159.25 |

## 3.3 各边框观测方式的作用

- **Profile 采样：**利用上一帧预测边框形成局部搜索范围，能够获得密集、精确的边缘候选；当前几何、时域和速度表现都最好，因此作为默认方案。
- **LSD：**几何精度接近 Profile，但该片段运行时间约为 Profile 的 4.8 倍，收益不足以抵消计算开销。
- **Hough：**轨迹看起来较平滑，但几何误差明显增大，说明稀疏或不稳定的线段不足以精确定位屏幕边缘。
- 三种变体均接受了所有帧、held frames 均为 0，因此差异来自边框观测质量，而不是冻结策略。

## 3.4 证据边界

- 当前检测器消融只在一个代表性滚动片段上完成，应作为针对性消融，不替代十片段主结果。
- LK/RANSAC、几何门控、自动重检和轨迹平滑在当前方案中有明确功能，但尚无对应的独立消融，因此不对这些模块给出超出已有实验的定量结论。

消融结论：

> 对当前管线而言，边框候选是否精确比单纯追求平滑更重要；局部 Profile 观测在当前测试中提供了最好的精度、稳定性与效率平衡。

# 4. 失败案例与局限分析

## 4.1 弱边缘或弱边框

弱边框不是当前方案的整体失败类别：我们的方法将该类别 RMSE 从逐帧检测的 157.26 px、光流的 155.87 px 降至 9.35 px，体现了局部边框搜索相对两种普通方法的优势。

但它仍是相对困难的场景：

- 一段弱边框片段的当前方案 RMSE 为 14.39 px，高于多数普通片段；
- 屏幕与背景对比度过低时，局部 profile 中的真实边界梯度会变弱；
- 错误纹理或背景边缘可能成为更强的候选；
- 四条边只要有一条证据不可靠，就可能影响交点和整个四边形。

可能的失效链：

```text
真实边框梯度过弱
→ Profile 候选点不足或落在背景纹理上
→ 边线拟合偏移或四边形不合法
→ 几何门控拒绝
→ 自动重检
→ 极端情况下保持上一有效四边形
```

需要明确：当前十片段主实验中 held frames 为 0，因此长期冻结是潜在风险，不是当前主结果已经发生的现象。

## 4.2 强反光

强反光仍是当前边框方案的主要潜在限制：

- 反光会遮挡真实屏幕边缘；
- 高亮区域的边界可能产生比真实边框更强的梯度；
- Profile 采样可能选中反光边缘，导致边线拟合偏移；
- 反光还会改变内部纹理，使 LK/RANSAC 的一致性诊断变得不稳定。

可能的失效链：

```text
反光遮挡真实边界并产生伪梯度
→ Profile 选择错误候选点
→ 四条边交点偏移
→ 候选通过时产生错误透视变换
   或
→ 候选被拒绝后触发重检/保持
```

## 4.3 改进方向

- 检测高亮饱和区域并降低反光梯度的权重；
- 综合局部 Profile、LSD 长线段、颜色差异和屏幕矩形约束；
- 为四条边分别输出置信度，并对低置信度边进行跨帧补全；
- 连续多帧边框失败时主动重新初始化；
- 扩充强反光、遮挡和极低对比度场景的标注与测试。

# 5. 总结

- 我们的方案在上一帧预测边附近进行局部 Profile 梯度采样，拟合四条物理边线并得到屏幕四边形；LK/RANSAC 只负责内容运动一致性诊断。
- 与逐帧检测相比，我们的方法减少了独立检测噪声和弱边框下的定位偏移；与相邻帧光流相比，我们的方法避免了滚动和视频内容驱动的累积漂移。
- 在十片段评估中，我们的方案达到 3.87 px 的 RMSE、0.996 的 IoU 和 2.45 px/frame 的平移变化，三项均优于逐帧检测和相邻帧光流。
- 最大优势出现在滚动和弱边框场景：滚动场景 RMSE 为 2.87 px，另外两种方法分别为 31.76 和 81.67 px；弱边框场景 RMSE 为 9.35 px，另外两种方法均超过 155 px。
- 检测器消融表明，Profile 采样比 LSD 更高效，比 Hough 更准确，是当前默认边框观测方式。
- 当前主要限制仍是反光、遮挡和极低对比度造成的边界证据退化；后续应加强多线索融合和失败恢复。

最终结论：

> 物理屏幕边框比单帧独立检测或内部内容光流更适合作为屏幕平面的主要证据，使我们的方法同时获得更高的几何精度和更好的时间稳定性。
