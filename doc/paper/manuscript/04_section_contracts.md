# Section Contracts

| Section | Purpose | Allowed claims | Forbidden claims / placeholders |
| --- | --- | --- | --- |
| Abstract | problem, implemented method, evaluation design | code-backed method description | all final numbers remain `[TBD]` |
| Introduction | motivate front-end preprocessing | literature-backed gap and task | no "first" or "state of the art" claim |
| Related Work | position rectification, tracking, stabilization | claims supported by local PDFs | no invented comparison to untested neural methods |
| Method | make current pipeline reproducible | exact current modules and equations | no proposal-only LSD/Hough consistency mechanism |
| Dataset | specify intended protocol | five planned categories and annotation schema | no assertion that 50 clips are complete |
| Experiments | freeze metrics and controls | script/run contracts | no final hardware or runtime until recorded |
| Results | provide insertion-ready narrative | neutral templates and conditional interpretation | no fabricated direction or significance |
| Discussion | explain possible outcomes and limitations | code and metric limitations | no causal claim without ablation |
| Conclusion | bounded summary | implemented system and evaluation plan | no numerical superiority before formal run |
