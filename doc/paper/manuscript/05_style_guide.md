# Style Guide

- Use direct engineering prose and define every acronym on first use.
- Use "proposed pipeline" rather than "novel" or "state-of-the-art".
- Separate implementation facts, experimental observations, and hypotheses.
- Use past tense only for implemented code and completed pilot validation; use future or placeholder language for formal results.
- Keep equations close to their definitions and state units.
- Refer to methods consistently as Frame-wise, Optical flow, and Proposed.
- Use "frequency diagnostics", never "moire suppression".
- Captions must state what is shown, the evaluation population, aggregation, and direction of improvement.
- English and Chinese versions must preserve identical claims, section order, equations, placeholders, and references.
