# Archive

本目录保留项目历史，不是当前论文的权威资料源。

- `development_notes/`：技术开发复盘和可选方法探针。
- `previous_drafts/`：已被当前论文工作区取代的旧稿件。
- `previous_plans/`：旧项目目标、方向决策、实验计划和答辩大纲。
- `../../scripts/archive/`：流水线重构前的实验、诊断和演示脚本。

本机旧试拍视频位于 `inputs/archive/pilot/`，旧实验产物位于
`runs/archive/pre_pipeline/`。两者都被 Git 忽略，只作为开发历史保留，
不计入正式 5 x 10 数据集和后续论文结果。

当前有效的论文输入、计划、证据和稿件统一位于 `doc/paper/`。
