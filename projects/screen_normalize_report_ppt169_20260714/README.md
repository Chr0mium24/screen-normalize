# Screen normalization final presentation

Custom 16:9 PowerPoint deck for an approximately six-minute ECE4512 presentation.

## Main files

- `exports/screen_normalize_final_15slides_en.pptx`: final English 15-slide deck with larger text and English speaker notes.
- `build_presentation_15.py`: reproducible `python-pptx` build script for the 15-slide deck.
- `preview_15_en_release/`: final PowerPoint-rendered QA previews for all 15 slides.
- `DATA_SOURCES_15.md`: slide-by-slide provenance for the 15-slide deck.
- `exports/screen_normalize_final_6min_en.pptx`: retained English eight-slide backup.
- `exports/screen_normalize_final_6min.pptx`: retained Chinese backup.
- `build_presentation.py`: reproducible build script for the English eight-slide backup.
- `images/`: repository figures copied into the presentation workspace.
- `sources/`: outline, manuscript, and ablation source documents.

The supplied proposal deck was used only as a visual reference. Proposal-stage result values were not reused.
